常見問題 (FAQ)

快速解決您關於資料更新、API 使用與介面操縱的常見疑惑。

如何使用本平台？

本平台免費開放給全台民眾使用，整合政府開放資料（TDX、中央氣象署、水利署等）。您可在首頁直接依分類（氣象、交通、監視器、防災）點選服務或搜尋。

各項監控資料多久更新一次？

全台路況監視器多數為 1~3 分鐘即時刷新；大眾運輸（雙鐵、公車、捷運）透過 TDX API 每秒至數秒動態推播；氣象與水利站數據每 10~15 分鐘定時更新。

如何取得開放數據與 API 存取權限？

本平台完全奠基於政府開放 API 數據。若您亦有開發需求，可直接至「交通部 TDX 服務平台」或「中央氣象署開放資料平台」免費申請金鑰。

若發現監視器無法顯示或資料異常？

部分地方監視器可能因現場保養或網路連線暫時離線。若發生廣泛斷訊，歡迎利用本頁表單回報，我們將即時會同開放 API 代理端進行維護。
